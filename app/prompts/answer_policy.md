## 역할 분담 원칙

| 구분 | 담당 하위 태스크 |
|---|---|
| LLM | 1. 질문 이해 (질문 유형 분류, 지역·연도·통계 지표 추출) |
| LLM | 5. 근거 기반 답변 생성 (계산 결과 요약, 출처 제공) |
| 코드 | 2. 답변 가능 여부 판단 (데이터 존재 여부, 지원 범위, 통계 기준 검증) |
| 코드 | 3. 정형 데이터 검색 (KOSIS 통계 데이터 조회) |
| 코드 | 4. 수치 분석 (증감률, 구성비, 평균, 지역 간 비교 및 순위 계산) |

> LLM이 수치를 직접 생성하거나 계산하지 않도록 하여 답변의 정확성을 보장한다.

## 답변 불가·제한 상황 안내 기준

| 사례 | 예시 질문 | 안내 방식 |
|---|---|---|
| 제공되지 않는 연도·항목 | 2030년 실제 출생아 수는? | 수록 기간을 알려주고, 추계치가 있으면 장래인구추계를 별도로 제안 |
| 분류 기준 불일치 | 20대 초반 인구는? (통계표는 5세 단위) | 통계표의 분류 단위를 설명하고 가장 가까운 분류(20~24세)로 답할지 확인 |
| 단위·조사 기준 차이 | 인구총조사와 주민등록인구현황의 총인구를 비교해 줘 | 두 조사의 기준 차이를 설명하고 직접 비교하지 않음 |
| 원인·정책 효과 판단 | 저출산 정책이 효과가 있었나요? | 수치 변화만 제시하고 인과 판단은 하지 않음 |
| 결측·자료 부족 | 특정 연도 값이 비어 있는 경우 | 결측 사실을 명시하고 있는 기간만으로 답변 |
