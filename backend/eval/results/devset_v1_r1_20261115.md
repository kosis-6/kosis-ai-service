**1. 답해야 할 문항을 거절함 (47건).** 거절할 때 돌려준 status는 다음과 같습니다.

**2. API 경로 문항 0/21.** 21문항 중 18문항을 거절했습니다(`out_of_range` 9, `tables` 5, `missing_data` 4). 2문항은 불필요하게 되물었고, 1문항은 표를 잘못 골랐습니다. 2005·2010년 인구총조사나 1970~80년대 인구동태처럼 적재되지 않은 옛 자료를 API로 가져오는 경로가 거의 동작하지 않습니다.

**3. 되묻기 누락 (11건).** D-106~D-115와 D-122는 되물어야 하는데 바로 답하거나 거절했습니다. 반대로 되물을 필요가 없는데 되물은 문항도 5건 있습니다(D-026, 068, 090, 105, 143).

**4. 답변 불가 25문항 중 정답 5문항.** "없는 연도" 5문항(D-126~D-130)만 모두 맞았습니다. 나머지는 다음과 같습니다.

- **사유 코드가 없어 유형을 정하지 못함 (9문항):** 챗봇이 `tables`로 거절해 채점에서 유형을 정할 수 없습니다. 범위 밖 주제 D-131, 133~135와 값이 비어 있음 D-141~144가 여기에 해당합니다.

## 정해야 할 것

1. 범위 밖 주제 문항에 대한 응답 "인구 분야 통계표에서 찾지 못함"(`tables`)을 범위 밖 거절로 인정할지, 아니면 전용 사유 코드를 붙일지.
2. 원인·예측 질문 D-146, 147, 150의 응답을 원인·예측 거절로 인정할지. 응답은 "원인은 판단할 수 없다"고 안내하고 대신 볼 수치를 보여 주지만, status가 `ok`라 지금은 "답변"으로 채점됩니다.
3. 연령 구간이 맞지 않을 때(`AgeMismatch`)의 결과가 지금은 `unknown_indicator`입니다. 이를 "맞는 구간 없음" 사유 코드로 나눌지.
