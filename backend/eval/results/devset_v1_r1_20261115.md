## 주요 문제

**1. 답해야 할 문항을 거절함 (47건).** 거절할 때 돌려준 status는 다음과 같습니다.

| `out_of_range` | 16 | 수록 기간 밖이라고 판단함. API 9건, 적재 7건 |
| `missing_data` | 6 | 자료가 없다고 판단함 |
| `unknown_region` | 1 | 지역을 인식하지 못함 |

**2. API 경로 문항 0/21.** 21문항 중 18문항을 거절했습니다(`out_of_range` 9, `tables` 5, `missing_data` 4). 2문항은 불필요하게 되물었고, 1문항은 표를 잘못 골랐습니다. 2005·2010년 인구총조사나 1970~80년대 인구동태처럼 적재되지 않은 옛 자료를 API로 가져오는 경로가 거의 동작하지 않습니다.

**3. 되묻기 누락 (11건).** D-106~D-115와 D-122는 되물어야 하는데 바로 답하거나 거절했습니다. 반대로 되물을 필요가 없는데 되물은 문항도 5건 있습니다(D-026, 068, 090, 105, 143).

**4. 답변 불가 25문항 중 정답 9문항.** "없는 연도" 5문항(D-126~D-130)과 범위 밖 주제 4문항(D-131, 133~135)을 맞혔습니다. 나머지는 다음과 같습니다.

- **거절하지 않고 통계표를 추천함 (5문항):** 실업률 질문에 인구총조사 표를 추천한 D-132, 값이 비어 있는 칸을 물었는데 표를 추천하거나 되물은 D-141~144입니다.
- **거절하지 않고 수치로 답함 (8문항):** 맞는 구간이 없는 D-136~138, 다른 지표로 답한 D-145, 원인·예측 질문 D-146, 147, 149, 150입니다.

## 정해야 할 것

1. ~~범위 밖 주제 문항의 "인구 분야 통계표에서 찾지 못함" 응답을 범위 밖 거절로 인정할지~~ → **정리됨 (11/17).** 이 문장은 통계표 찾기가 `out_of_scope`로 거절할 때만 나오는 고정 문구라 범위 밖 거절로 채점합니다. 다음 평가부터는 채점표 "거절 근거" 칸에 범위 밖 단어·LLM 검토·점수 문턱 중 어디서 거절했는지 남습니다. 사용자에게 보이는 문구가 LLM이 범위 밖으로 판단한 경우에도 "찾지 못했습니다"라서 애매하다는 점은 남아 있습니다.
2. ~~원인·예측 질문 D-146, 147, 150의 응답을 원인·예측 거절로 인정할지~~ → **정리됨 (11/17): 오답으로 유지.** 지금 챗봇은 "원인은 판단할 수 없다"는 문구를 붙인 뒤 수치로 답합니다(`ok`). 골든셋이 기대하는 행동은 답변 불가 + 볼 수 있는 통계 안내라서 채점 방식은 그대로 둡니다. 챗봇을 이 방식으로 바꿀 예정입니다.
   - D-146, 147, 150: "왜·원인" 질문(`CAUSAL`, `qa.py`)을 수치 답 대신 답변 불가로 돌리고 볼 수 있는 통계를 안내해야 함
   - D-149 ("앞으로 출산율 다시 오를까?"): 예측 표현을 감지하지 못해 추이로 답함. 예측 질문 감지부터 필요함
   - D-148 ("2040년 해운대구 인구"): "없는 연도"로 거절함. 원인·예측 거절로 바꾸고 시도 장래추계(부산 2040년)를 안내해야 함
3. ~~연령 구간이 맞지 않을 때(`AgeMismatch`)의 결과를 "맞는 구간 없음" 사유 코드로 나눌지~~ → **정리됨 (11/17): 오답으로 유지, 챗봇을 고침.** "맞는 구간 없음" 5문항 중 `AgeMismatch`까지 간 문항은 없었습니다. 고칠 것은 다음 세 가지입니다.
   - **조건을 버리고 전체 값으로 답함 (D-136~138):** 체중(3.2kg)·결혼기간(1년 반)·동거기간(7년 반)처럼 지원하지 않는 조건을 버리고 전국 출생아·이혼 건수로 답했습니다. 지원하지 않는 조건이 있으면 버리지 말고 거절하거나, 반영하지 못했다고 알려야 합니다.
   - **"~에서 ~사이", "~부터 ~까지" 연령을 못 읽음 (D-139, 140):** 연령 정규식(`qa.py`)이 `62~67세`처럼 물결표·하이픈만 읽습니다. "62살에서 67살 사이", "33살부터 38살까지"를 읽게 해야 합니다. D-140은 등록외국인을 외국인주민으로 읽은 문제도 있습니다.
   - **연령 구간이 맞지 않을 때의 응답:** 지금은 `unknown_indicator`("질문한 연령 구간으로 나눈 자료가 없습니다")로 돌려줘(`lookup.py`) 범위 밖 주제로 채점되고, 대신 볼 수 있는 구간 안내도 없습니다. 전용 status(예: `band_mismatch`)로 표에 있는 구간(예: 30~34세, 35~39세)을 안내하고, 채점의 `REFUSAL_TYPES`에 "맞는 구간 없음"으로 한 줄 추가합니다.
