### A. 근소한 오답 69개: 정답이 바로 옆에 있음

**정답이 몇 위였나**

| 정답 순위 | 2위 | 3위 | 4위 | 5위 | 6~9위 |
| --- | --- | --- | --- | --- | --- |
| 문항 | 36 | 13 | 3 | 7 | 10 |

- 69개 중 49개(71%)가 2~3위입니다. 검색은 정답 근처까지 왔지만 마지막 한 칸을 못 고른 경우입니다.

**1위로 잘못 고른 표가 정답 표와 어떤 관계인가**

| 관계 | 문항 | 예 (질문 → 1위로 고른 표 / 정답 표) |
| --- | --- | --- |
| 같은 조사의 형제 표 (분류 축이 다름) | 46 | "혼자 산 지 10년 넘은 사람" → 1인가구**사유별**/혼자산기간별 / 혼자산기간별 |
| | | "애 낳은 엄마들 중 일하는 사람 비율" → 출생자녀수별/**추가자녀계획수별** / 출생자녀수별 |
| | | "출퇴근할 때 어떤 교통수단" → 성, **산업** 및 교통수단별 / 성별/연령별/교통수단별 |
| 다른 조사의 비슷한 표 | 12 | "국적별 외국인 입국자 수" → 인구총조사 입국연도별 외국인 / 출입국 통계 입국자 |
| | | "옛날부터 지금까지 기대수명" → **장래인구추계** 기대수명 / 인구동향 기대수명 |
| 사할린 조사: 항목마다 표가 나뉨 | 6 | "복지관이나 지원센터 이용" → 지원센터 표 / 사회복지관 표 |
| 특정 시도 전용 표가 이김 | 3 | "어린이가 몇 명인지 읍면동별로" → **충청북도** 총조사인구 / 연령 및 성별 인구 – 읍면동 |
| (쌍태아 이상) 변형 표가 이김 | 2 | "결혼하고 몇 년 만에 첫 아이" → 결혼생활기간별 출생**(쌍태아 이상)** / 결혼생활기간별 출생 |

**원인**
1. **질문이 묻지 않은 분류 축을 충분히 감점하지 않습니다.** 형제 표는 이름의 대부분이 겹치고 분류 축 하나만 다릅니다. 질문에 없는 축(사유별, 산업, 추가자녀계획수별, 쌍태아 이상)이 붙은 표가 키워드나 임베딩 점수로 이깁니다. `search.unasked_modifiers`가 일부를 감점하지만 이런 축까지는 다루지 못합니다.
2. **LLM 최종 검토가 순위를 바꾸지 않습니다.** filter 모드라 1위가 질문에 맞으면 그대로 둡니다. 2위가 더 정확해도 고르지 않습니다.
3. **특정 지역 전용 표.** 질문에 그 지역이 없는데 "충청북도 …", "전북특별자치도 …", "대구광역시 …" 표가 이깁니다. 읍면동이나 각세별처럼 질문의 단어와 겹치는 부분이 커서입니다.
4. **정답 기준이 좁은 문항도 있습니다.** 사할린 조사는 "복지관이나 지원센터"처럼 질문이 두 항목을 함께 묻는데 정답은 한 항목의 표만 인정합니다. 지역별로 나뉜 통근 표(광주·전남 / 부산·울산·경남)도 질문에 지역이 없는데 정답이 한 지역입니다. 이런 문항은 코드 문제라기보다 정답에 여러 표를 인정하거나, 되묻기를 정답으로 보는 게 맞을 수 있습니다.

## 개선 제안 (우선순위)

`new_dev100_draft.jsonl`(새셋)은 테스트용 문항이라, 이 문항의 오답에 맞춰 규칙을 고치지 않습니다(측정 자료 README). 아래 제안은 개발 셋에서 같은 유형을 확인하고, 새셋으로는 결과만 재야 합니다. 근소한 오답 69개 중 26개가 새셋 문항입니다.

| 순위 | 제안 | 겨냥하는 오답 | 비용 |
| --- | --- | --- | --- |
| 1 | **LLM 검토의 거절 기준 보강**: 수록 기간은 후보 정보의 기간 칸으로 판단하고, 연도만으로 거절하지 않게 프롬프트 수정. `OFF_DOMAIN`의 "월급"은 "월급 받고 일하는"(임금근로자)일 때 빼기 | C 3개 | 작음 |
| 2 | **묻지 않은 분류 축 감점 확대**: "(쌍태아 이상)", 사유별, 추가계획별처럼 질문에 없는 축과, 질문에 없는 특정 시도 전용 표를 감점 | A 일부 + `x09` | 중간 |
| 3 | **LLM 검토 모드 재측정**: `pick`, `resolve` 모드로 2~3위 정답을 고를 수 있는지 개발 셋에서 측정 | A (정답 2위 36개) | HCX 측정 1회 |
| 4 | **일상어 사전 보강**: B의 표현(주간인구, 생산연령인구, 숙박·음식점업, 재혼, 전출, 외국인 근로자 등) | B 13개 | 작음 |
| 5 | **계획 보정**: 파생 지표 규칙을 지표가 여럿일 때도 질문 원문으로 확인 (`m21`). 성비처럼 계산 지표가 들어간 질문은 기초 지표로 나누기 (`m18`) | 여러 표 2문항 | 중간 |
| 6 | **범위 밖 단어 보강**: 어린이집, 연금, 장려금, 실업률 | 범위 밖 6개 중 4개 | 작음 |
| 7 | **정답 기준 정리**: 사할린 항목별 표, 지역별로 나뉜 표처럼 질문이 한 표를 특정하지 못하는 문항은 여러 표를 정답으로 인정하거나 되묻기를 정답으로 | A 일부 (점수 왜곡) | 작음 |
