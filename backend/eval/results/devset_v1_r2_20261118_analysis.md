## 4. 정해야 할 것 (골든셋 기준 · 정책)

1. **"요즘 · 몇 년 새"의 기간** — 챗봇은 2020~2025(6개 연도), 골든셋은 2021~2025(최근 5년)
   (D-038 · 044 · 121). D-036은 2022~2024, D-040 "재작년 vs 작년"은 2022~2023으로 읽었다.
   → 기본 기간을 "최근 5개 연도"로 맞출지, 골든셋에서 둘 다 인정할지
2. **되묻기 기준** — 골든셋은 기준이 여럿인 질문(외국인 = 등록외국인/체류외국인/외국인주민, 가구 = 일반가구/세대,
   이혼율 = 조이혼율/일반이혼율, 청년 = 15~29/19~34세)에 되묻기를 기대하는데, 챗봇은 기본값으로 답하고 기준을 적는다 (9건).
   → "기본값으로 답하고 기준 안내"를 정답으로 볼지, 되물어야 할지
3. **대안 숫자** — 조건을 다 맞추지 못하면 "대신 이런 자료"로 숫자를 보여 주고 고르게 한다.
   D-020 · 052(1970년대 부산 혼인)는 대안 숫자가 정답과 같은데 되묻기 · 환각으로 채점된다 (환각 9건 중 5문항이 이 경우).
   → 대안이 질문 조건을 모두 만족하면 바로 답할지 / 채점에서 대안 숫자를 어떻게 볼지
4. **비교 답에 "몇 배"를 넣을지** — D-062 · 069는 차이는 맞고 배수가 없어 요약 오류. **구성비 답에 분자 · 분모를 넣을지** — D-087은 비율은 맞고 분자 · 분모가 없어 계산 오류
5. **표에 없는 세부 조건이 섞인 질문** — D-143 · 145(세대구성 조건)는 조건을 빼고 연령 인구만 답했고,
   D-138(7년 6개월)은 "7년"으로 답했다. 골든셋은 답변 불가(값이 비어 있음 · 맞는 구간 없음)를 기대한다.
   → 조건을 뺀 값을 답으로 내면 안 된다는 원칙으로 갈지

## 5. 개선 필요

### 코드
1. **표를 찾고도 거절 (15건 중 11건이 "추천 통계표" 안내로 끝남)** — 국제결혼 합계, 다문화 추이, 이혼 평균 연령, 초혼 나이 차이,
   기대수명 차이, 출생 성별 비교, 통근 수단 비교, 인구 감소 순위, 미성년 자녀 비율 등. 표 찾기 다음 계산으로 넘기는 연결이 아직 약하다.
2. **인구 통계 지표 표(DT_1IN2030) 미지원** — 노령화지수 · 노년부양비 · 중위연령 · 평균연령을 주민등록인구로 직접 계산하거나 다른 값을 낸다
   (D-064 · 097 · 098 · 100). 사전에 이 표를 지표로 넣으면 4건 이상 해결
3. **연도 없는 질문이 옛 연도로 감 (D-004, 새로 틀림)** — "이혼 몇 건이나 돼?"를 1980년 API 표(DT_1B80030)로 답했다. 연도를 안 말하면 최신 연도
4. **묶음 지역** — "강남3구" 인식 실패(D-032). 수도권 다문화 출생아 합계가 다른 값으로 바뀜(D-029, 변형셋 P-029와 같은 원인)
5. **되물은 뒤 최종 답 없음 (5건)** — 지역을 받고도 같은 질문을 다시 하거나(D-119 · 125), 시군구 자료가 없다고 끝남. 받은 답을 이어 받기
6. **비슷한 표 고르기** — 쌍둥이(쌍 vs 명, D-010), 출생성비(D-101), 주간인구(D-018), 외국인 주민 비율 기준 표(D-094), 2010년 통근(2020년 표, D-095)
7. **불필요한 되묻기** — 지역이 없는 질문은 전국으로(D-015 · 092)
