# 2026년 행정구역 개편: 지역 마스터에 새 코드 반영 요청 (데이터 엔지니어링)

2026-11-22 작성. 챗봇 쪽은 임시로 막아 두었고(아래 "지금 챗봇은"), 근본 해결은 지역 마스터 갱신이 필요하다.

## 무엇이 문제인가

KOSIS 주민등록인구 월별 자료(DT_1B04006, `prdSe=M`)는 2026년 10월 말 기준으로 **새 행정구역 코드**로 나온다.
우리 지역 마스터(`regions`)와 연간 수집본(`population`, 2025년까지)은 **옛 코드**라서 월별 값과 이어지지 않는다.

`regions`에는 시도 `12`(전남광주통합특별시, `valid_from=2026`)만 있다. 그 아래 시군구와 인천 · 화성의 새 구는 없다.
개편 기록은 `region_changes`에 이미 3건 있다 (전남광주 통합, 인천 개편, 화성시 일반구 신설).

## 코드 차이 (2026년 10월 말 KOSIS 월별 vs 2025년 연간 수집본)

KOSIS 월별 297곳, 연간 수집본 295곳.

### 1. 전남광주통합특별시 (2026-07-01): 광주 `29` + 전남 `46` → `12`

| 옛 코드 (우리) | 새 코드 (KOSIS) |
|---|---|
| `29` 광주광역시, `46` 전라남도 | `12` 전남광주통합특별시 |
| `29110` 동구, `29140` 서구, `29155` 남구, `29170` 북구, `29200` 광산구 | `12210` 동구, `12240` 서구, `12270` 남구, `12300` 북구, `12330` 광산구 |
| `46110` 목포시 ~ `46910` 신안군 (22곳) | `12110` 목포시 ~ `12870` 신안군 (22곳) |

전남 시군의 새 코드는 `46xxx` → `12xxx`로 끝 세 자리가 대체로 유지된다 (예: `46110` 목포시 → `12110`, `46910` 신안군 → `12870`처럼 다른 것도 있음). **이름 기준으로 1:1 대조 필요.**
광주 자치구는 이름이 "동구 · 서구 · 남구 · 북구"라 다른 시도의 같은 이름과 섞이지 않게 상위 지역까지 포함해 대조해야 한다.

### 2. 인천 행정구역 개편 (2026-07-01): 범위가 바뀜 (1:1 아님)

| 옛 코드 | 새 코드 |
|---|---|
| `28110` 중구, `28140` 동구 | `28125` 제물포구 (99,159명), `28155` 영종구 (139,973명) |
| `28260` 서구 | `28275` 서해구 (392,254명), `28290` 검단구 (279,433명) |

옛 구와 새 구의 경계가 달라 **옛 이름을 새 이름의 별칭으로 잇지 말 것.** 제주시처럼 "변동전 지역 (범위가 달라 연결하지 않음)"으로 처리하는 기존 관례(`region_code_map.unmatched_reason`)를 따르면 된다.

### 3. 경기 화성시 일반구 신설 (2026-02-01)

| 옛 코드 | 새 코드 |
|---|---|
| `41590` 화성시 (유지), `41592` 화성시동부출장소, `41594` 화성시동탄출장소 | `41591` 만세구, `41593` 효행구, `41595` 병점구, `41597` 동탄구 |

## 요청 사항

1. **`regions`에 새 코드 35곳 추가** (`valid_from=2026`). 전남광주 시군구 27곳 · 인천 4곳 · 화성 4곳
2. **옛 코드에 `valid_to=2025`** 표시. 지금 `28110` · `28140` · `46`은 `valid_to=2025`인데, `29` 계열 · `46xxx` 시군구 · `41592` · `41594`는 비어 있거나 일관되지 않다 (예: `29110` 광주 동구 `valid_to=None`)
3. **옛 ↔ 새 대응표**: 1:1로 이어지는 곳(전남 시군, 광주 자치구)만 연결하고, 범위가 바뀐 곳(인천, 화성)은 연결하지 않는다는 표시
4. **`region_aliases`**: "광주", "전남", "광주광역시", "전라남도"로 묻는 질문을 2026년 이후 어떻게 읽을지 결정 필요. 2025년까지 자료는 옛 시도로 있으므로 연도에 따라 갈린다
5. **연간 수집본 2026년 갱신 시**: 2026년 12월 말 연간 자료부터 새 코드로 들어오므로, 같은 갱신 때 위 1~3이 먼저 들어가 있어야 한다

## 지금 챗봇은 (임시 처리, PR `fix/trend-end-note`)

- 연도를 말하지 않은 질문은 KOSIS 최신 달(2026년 10월 말)로 답한다
- 그런데 최신 달 **순위**에서 지역이 빠지면(시도 순위 17 → 16곳, 전국 시군구 229 → 199곳) 연간 마지막 해(2025년)로 답하고 이유를 밝힌다
- **값 · 비교**는 옛 코드로 최신 달을 요청하면 KOSIS가 "데이터가 존재하지 않습니다"를 돌려줘, 연간 값으로 답한다 (예: "전남 인구"는 2025년 12월 말 값)

지역 마스터가 갱신되면 위 임시 처리 없이 최신 달로 답할 수 있다. 갱신 후 확인할 질문:
"인구 많은 시도 순위", "인구 많은 시군구 순위", "전남 인구", "순천시 인구", "인천 서해구 인구", "화성시 동탄구 인구"

## 확인 방법

```bash
cd backend
PYTHONPATH=. python - <<'EOF'
from app.services import population_latest as pl, indicators as ind
rows = pl._fetch_month("ALL", pl.SEX_ITEM["계"])
kosis = {str(r["C1"]): r["C1_NM"] for r in rows if str(r.get("C2_NM")) == "계"}
regions = {r["region_code"] for r in ind._rows("select region_code from regions")}
print("KOSIS에만 있는 코드:", sorted(set(kosis) - regions))
EOF
```
