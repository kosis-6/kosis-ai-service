## 1. 큰 원칙: LLM은 질문 해석만 한다

| 구분 | 맡는 일 |
|---|---|
| LLM | 질문 이해: 질문 유형 분류, 지역·연도·지표 뽑기 |
| 코드 | 답할 수 있는지 판단 (자료가 있는지, 지원 범위인지, 통계 기준이 맞는지) |
| 코드 | KOSIS 통계 조회 |
| 코드 | 계산 (증감률, 구성비, 평균, 지역 비교·순위) |
| 코드 | 답 문장 만들기 (질문 유형별 템플릿에 계산 결과·출처·링크를 채움) |

- 답에 나오는 숫자와 문장은 모두 코드가 만든다.
- 계산 결과에 없는 숫자, 원인·예측·정책 평가 문장은 **환각**으로 센다.

질문 유형: `value`(한 값) · `trend`(추이) · `compare`(지역 비교) · `rank`(순위) · `composition`(구성비) · `causal`(원인·정책) · `other`(통계와 관계없음)

## 2. 답의 모양

```
본문 (질문 유형별 템플릿)
※ 계산식: …
※ 지표 정의              ← 지표 설명은 늘 붙인다
※ 기준·기본값 안내        ← 3장·4장
출처: 작성기관 (기준 시점)
통계표: KOSIS 링크        ← 표가 여럿이면 표마다 출처와 링크
```

- 출처에는 **통계표명, 작성기관, 기준 시점, KOSIS 링크** 네 가지가 모두 있어야 정답으로 본다.

## 3. 조건이 빠졌을 때 쓰는 기본값

| 빠진 조건 | 기본값 | 답에 붙는 안내 |
|---|---|---|
| 연도 | 그 지표 표의 최신 시점 (인구는 최신 달) | "가장 최근 자료인 ○○ 기준으로 답했습니다" |
| 연도 (최신 달을 쓸 수 없을 때) | 최신 연간 자료 | "최신 달 자료는 행정구역 개편으로 일부 지역이 달라 쓰지 않았습니다" |
| 추이 기간 | 최근 6개 연도. LLM이 짐작한 기간은 지운다 | 끝 연도를 직접 말했을 때만 "~년까지 봤습니다" |
| 성별 | 계(남녀 전체). LLM이 짐작한 남/여도 지운다 | 남편·아내·미혼모처럼 말 자체에 성별이 든 경우는 그대로 둔다 |
| "남녀", "성별"을 물음 | 남·여를 따로 보여 주고 더하지 않는다 | 성비·인구밀도·세대당 인구는 나누지 않는다 |
| 지역 | 전국 (비교·순위는 시도별 + 전국 기준선) | |
| 같은 수치의 표가 여럿 | 최신판. 둘 다 최신이면 기간이 긴 표 | |
| 하위 구분이 있고 계가 있음 | 계 + 구분별 값 | |

## 4. 기준이 여럿인 말: 되묻지 않고 기본값으로 답한 뒤 기준을 안내한다

되묻기는 한 턴이 더 들고, 대부분의 사용자는 대표 기준의 값을 원한다. 그래서 기본 기준으로 답하고, 어떤 기준으로 답했는지와 다른 기준이 무엇인지 ※ 줄로 밝힌다.

| 질문의 말 | 기본값 | 함께 안내하는 다른 기준 |
|---|---|---|
| 인구, 인구수, 전체 인구 | 주민등록인구 (내국인, 12월 31일) | 인구총조사 인구, 장래추계인구 |
| 노인 비율, 고령화율 등 | 고령인구 비율 (65세 이상 ÷ 주민등록인구) | 노령화지수 |
| 부양비 | 총부양비 | 노년부양비, 유소년부양비 |
| 성비, 남녀 비율 | 여자 100명당 남자 | 출생성비 |
| 출산율 | 합계출산율 | 조출생률 |
| 사망률 | 조사망률 (인구 1,000명당) | 연령표준화 사망률, 영아사망률 |
| 혼인율, 결혼율 | 조혼인율 | 일반혼인율 |
| 이혼율 | 조이혼율 | 유배우 이혼율, 혼인 대비 이혼 건수 |
| 외국인 수 | 외국인주민 수 (행정안전부) | 법무부 등록외국인 수 |
| 외국인 비율 | 외국인주민 비율 | 등록외국인 비율 |
| 평균 출산연령 | 모의 평균 출산연령 | 첫째아 평균 출산연령 |
| 연령 집단 (청년·노인 등) | 청년 19~34세, 노인 65세 이상, 어린이 0~14세, 청소년 9~24세, 중장년 40~64세 등 | 다른 법·통계의 연령 기준 |

답에 나오는 모습:

```
※ 이혼율은 조이혼율(인구 1,000명당 이혼 건수)로 답했습니다. …
※ '청년'은 19~34세로 계산했습니다 (청년기본법 19~34세 · 고용 통계는 15~29세)
```

- 정확한 지표 이름(예: "조이혼율")으로 물으면 안내하지 않는다.
- 오타(예: "합계출생율")는 "'합계출생율'을 합계출산율로 보고 답했습니다"로 안내한다.

## 6. 답할 수 없을 때: 유형을 알리고 대신 볼 수 있는 범위를 안내한다

| 유형 | 예 | 안내 |
|---|---|---|
| 없는 연도·예측 | "2030년 실제 출생아 수" | 수록 기간을 알려 주고, 추계치가 있으면 장래인구추계를 제안 |
| 원인·정책 효과 | "저출산 정책이 효과가 있었나?" | 수치 변화만 보여 주고 인과 판단은 하지 않음 |
| 조사 기준이 다름 | "인구총조사와 주민등록인구 비교" | 두 조사의 기준 차이를 설명하고 직접 비교하지 않음 |
| 값이 비어 있음 | 특정 연도 결측 | 비어 있다고 밝히고 있는 기간만으로 답함 |
| 그 지역 단위로 집계되지 않음 | 읍면동 단위 질문 | 시군구·시도로 다시 물어 달라고 안내 |
| 두 조건을 함께 집계한 표 없음 | | 조건을 하나씩 나눠 물어 달라고 안내 |
| 조건 일부만 맞는 표 | | 조건을 빼거나 표에 있는 구분으로 다시 물어 달라고 안내 |
| 행정 절차 | "전입신고 어떻게 해?" | 정부24·주민센터를 안내하고 질문 예시를 보여 줌 |
| 추천·의견 | "살기 좋은 동네 추천" | 판단에 참고할 통계 예시를 보여 줌 |
| 통계 질문이 아님 | 날씨, 인사 등 | 질문 예시를 보여 줌 |

## 7. 후속 질문

- 사용자가 바꾼 조건만 바꾸고 나머지는 그대로 둔다.
- 후속 질문은 네 종류로 나눈다.

| 종류 | 예 | 하는 일 |
|---|---|---|
| `change` | "서울도 같이", "2022년만", "남자만" | 조건 일부만 바꿈 |
| `chart` | "막대그래프로" | 숫자는 그대로 두고 그림만 바꿈 |
| `summary` | "한 줄로 요약해줘" | 조건을 바꾸지 않고 직전 답을 다시 정리 |
| `new` | "2024년 전국 합계출산율 알려줘" | 새 질문으로 처리 |

- 조건을 바꾸면서 요약을 원하면(예: "2022년만 요약해줘") `change`로 본다.

## 8. 숫자 표기와 정답 인정

- 비율의 차이는 **%p**로 쓴다 (예: "7.8%p 높음").
- 반올림 차이는 정답이다 (20.6%와 20.62%).
- 단위를 환산해 같으면 정답이다 (52,000명과 5.2만 명).
- 정답 표와 다른 표를 써도 같은 숫자를 맞게 전달했으면 정답이다.

질문 종류별로 맞아야 하는 숫자:

| 질문 종류 | 맞아야 하는 것 |
|---|---|
| 단순 수치 | 값 |
| 집계 | 합산 대상과 합계 |
| 추이 | 증감량, 증감률, 연평균 증가율 |
| 비교 | 차이(%p)와 배수 |
| 순위 | 순서와 상위 N개 |
| 구성비 | 분자·분모와 비율 |

## 9. 정리가 필요한 것

1. **되묻기 기준이 문서마다 다르다.** 채점 기준(`scoring_rubric.md`)의 확정 규칙은 "정의가 다른 대상이면 되묻기"인데, 지금 코드는 4장처럼 기본값으로 답하고 기준을 안내한다. 개발셋 v2의 되묻기 문항(V2-106~V2-116)과 멀티턴 M-02의 기대 행동을 "답변 (기본값 + 기준 안내)"으로 바꾸지 않으면 채점에서 "되묻기 누락"으로 잡힌다.
2. **`answer_policy.md`가 오래되었다.** 3장(기본값), 4장(기준 안내), 최신 시점 안내가 빠져 있다.
