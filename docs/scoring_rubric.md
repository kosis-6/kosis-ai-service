## 채점 방법

**원칙: 사람 채점은 최소화하고 코드로 자동 채점한다.** 사람은 1차 평가 때 한 번 직접 채점하고, 그 결과로 자동 채점을 검증한 뒤에는 자동 채점만 쓴다.

- 문항 하나를 한 줄로 채점한다.
- 자동 채점을 위해 챗봇은 문항마다 응답 종류(답변 / 되묻기 / 답변 불가), 선택한 표, 조회 조건, 계산 결과, 답변 불가 유형과 안내 틀 ID를 기록한다.

### 칸별 자동 채점 방법

| 칸 | 자동 채점 방법 |
| --- | --- |
| 실제 행동 | 기록된 응답 종류와 기대 행동 비교 |
| 숫자 | 답변에서 숫자를 뽑아 정답 수치와 비교 (반올림·단위 환산 허용) |
| 조건 | 기록된 조회 조건과 정답 조건 비교 |
| 출처 | 4요소(통계표명, 작성기관, 기준시점, kosis 링크)가 있는지, 링크가 정답 표로 연결되는지 문자열로 확인 |
| 답변 불가 | 기록된 불가 유형과 골든셋 유형 비교, 대안 문구가 들어간 안내 틀인지 틀 ID로 확인 |
| 환각 숫자 | 답변 속 숫자를 모두 뽑아 계산 결과 목록에 없는 숫자 세기 |
| 환각 문장 | LLM이 원인·예측·정책 평가 문장인지 판정 |
| 틀린 이유 | 실행 기록을 앞 단계부터 비교해 처음 어긋난 단계를 표시 (행동 → 표 → 조건 → 계산 → 요약) |

### 사람이 하는 일

1. **골든셋 정답 작성과 교차 확인**: 자동 채점의 기준이므로 2명이 확인한다.
2. **LLM 판정 검수**: 환각 문장 판정 결과 중 일부(예: 20건)를 확인해 믿을 만한지 본다.
3. **자동 채점 검증**: 1차 평가의 수동 채점 결과와 자동 채점 결과를 비교해 일치율을 낸다. 일치율이 충분하면 이후 회차는 자동 채점만 쓰고, 다른 문항만 사람이 확인한다.

## 정답 인정 기준

- **숫자**: 반올림 차이는 정답 (20.6%와 20.62%)
- **단위**: 환산해서 같으면 정답 (52,000명과 5.2만 명)
- **비율 차이**: %p로 표시해야 정답 ("7.8%p 높음")
- **통계표**: 정답 표와 달라도 같은 숫자를 맞게 전달했으면 정답
- **조건이 빠진 질문**: "답변 기본값·되묻기 규칙"의 확정 규칙 8개대로 답했으면 정답

| 확정 규칙 요약 | 정답 행동 |
| --- | --- |
| 기간 없음 | 최신 시점 |
| 같은 수치의 표가 여러 개 | 최신판, 둘 다 최신이면 기간이 긴 표 |
| 성별 없음 | 계(남녀 전체) |
| 하위 구분이 있고 계 있음 | 계 + 구분별 값 |
| 정의가 다른 대상 | 되묻기 |
| 지역 없음 | 전국 (비교·순위는 시도별 + 전국 기준선) |
| "우리 동네", "여기" | 되묻기 |
| 기본값 사용 | 기준 한 줄 표시 |

## 항목별 채점

| 항목 | O 기준 | X일 때 기록 |
| --- | --- | --- |
| **정답** | 숫자·조건·출처(표명·기관·기준 시점·링크)가 모두 맞음 | 틀린 칸 표시 |
| **응답 행동** | 기대 행동(답변 / 되묻기 / 답변 불가)과 같음 | 되묻기 누락 / 불필요한 되묻기 / 그 외 |
| **답변 불가** | 유형이 맞고, 대신 볼 수 있는 범위를 안내함 | 유형 오류 / 대안 없음 |
| **환각** | 계산 결과에 없는 숫자, 원인·예측·정책 평가 문장이 없음 | 해당 문장 건수 |
| **연속 대화** | 후속 턴에서 바꿀 조건만 바꾸고 나머지는 유지함 | 조건 누락 / 잘못 변경 |

### 되묻기 문항

챗봇이 되물으면 골든셋에 적어 둔 사용자 답을 넣어 이어서 실행하고, 최종 답까지 맞아야 정답이다. 되묻지 않고 바로 답했으면 숫자가 맞아도 되묻기 누락으로 기록한다.

### 질문 종류별 숫자 기준

| 질문 종류 | 맞아야 하는 것 |
| --- | --- |
| 단순 수치 | 값 |
| 집계 | 합산 대상과 합계 |
| 추이 | 증감량, 증감률, 연평균 증가율 |
| 비교 | 차이(%p)와 배수 |
| 순위 | 순서와 상위 N개 |
| 구성비 | 분자·분모와 비율 |

## 채점 기록 양식

| 문항 | 세트 | 기대 행동 | 실제 행동 | 숫자 | 조건 | 출처 | 환각 | 정답 | 틀린 이유 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Q-001 | 개발셋 | 답변 | 답변 | O | O | O | 0 | O |  |
| Q-002 | 개발셋 | 되묻기 | 답변 |  |  |  | 0 | X | 행동 (되묻기 누락) |
| Q-003 | 테스트셋 | 답변 | 답변 | X | O | O | 1 | X | 계산 |

틀린 이유는 하나만 적는다: **행동 / 표 / 조건 / 계산 / 요약**. 처음 틀린 단계를 고르고, 회차가 끝나면 이유별 건수를 세어 다음에 고칠 곳을 정한다.
